# Phase 7 model candidates (decision pending)

These are candidates for review only. No model was downloaded or selected. Sizes are approximate download sizes for the cited artifact and exclude application/runtime code unless stated.

| Feature                       | Candidate                                            | License    |                                                             Approx. model size | Quality and limits                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------- | ---------------------------------------------------- | ---------- | -----------------------------------------------------------------------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OCR                           | Tesseract `tessdata_best`, English `eng.traineddata` | Apache-2.0 |                                                            22.4 MB for English | Higher accuracy and slower than `tessdata_fast` in Tesseract's own comparison. Focused on OCR; the project has not benchmarked handwriting, receipts, or language-specific accuracy. [Model file](https://github.com/tesseract-ocr/tessdata_best/blob/main/eng.traineddata), [comparison](https://tesseract-ocr.github.io/tessdoc/Data-Files.html) |
| Portrait background removal   | `Xenova/modnet`                                      | Apache-2.0 | Repository about 110 MB; exact browser artifact must be pinned before choosing | Built for portrait matting, not arbitrary object or scene segmentation. The model card provides no VISTA-relevant accuracy benchmark. [Model card](https://huggingface.co/Xenova/modnet)                                                                                                                                                           |
| Object removal                | `othytenk/lama-int4-int8`                            | Apache-2.0 |                                                                    About 37 MB | Quantized LaMa inpainting, documented at 512×512 patches/crops. Its card reports 31.4 dB average and 24.2 dB worst PSNR against fp32; these are fidelity comparisons, not user-perceived quality scores. Requires a compatible ONNX Runtime and should be checked on target browsers. [Model card](https://huggingface.co/othytenk/lama-int4-int8) |
| Natural-language image search | `Xenova/clip-vit-base-patch32` quantized ONNX        | MIT        |         About 153 MB for the quantized ONNX model, plus tokenizer/config files | Produces text/image similarity embeddings; similarity is not factual verification, and VISTA has no task-specific relevance or bias evaluation. [Model card](https://huggingface.co/Xenova/clip-vit-base-patch32), [quantized file](https://huggingface.co/Xenova/clip-vit-base-patch32/blob/main/onnx/model_uint8.onnx)                           |

`briaai/RMBG-2.0` is excluded from the shortlist: its model card lists CC BY-NC 4.0 and gated access, so commercial use requires a separate agreement. [Model card](https://huggingface.co/briaai/RMBG-2.0)

Before Phase 7, choose the model(s), confirm whether the intended hosting is static hosting only or another arrangement, and confirm whether these licenses and their notice/attribution requirements are acceptable. Model quality must then be benchmarked against representative, locally generated or user-approved fixtures before VISTA claims accuracy.
