# Changelog

User-facing changes to VISTA. Unreleased entries describe the current working
tree; this file does not imply a release or commit.

## Unreleased

- Added local library sorting, filtering, search, album management, recoverable
  trash, and whole-library backup/restore.
- Added non-destructive editing with an edit stack and save-as-copy.
- Added conversion, target-size compression, batch copy, and export tools.
- Added duplicate and image-health review with cached analysis.
- Added profile/social image creation, contact sheets, and PDF output.
- Documented browser support, security/privacy limitations, and platform
  preset sources.
- OCR, receipt extraction, and AI/model features remain gated on model license
  and hosting decisions.
